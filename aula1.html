Introdução ao Linux

Entenda como o sistema operacional Linux organiza arquivos e diretórios, e aprenda os comandos essenciais para navegar e manipular o sistema pela linha de comando.

1.1 Sistema de arquivos

Linux é um sistema operacional de código aberto baseado em Unix. Existem várias distribuições (Ubuntu, Debian, Fedora, etc.); neste curso usaremos o Ubuntu. Toda a hierarquia de arquivos parte de um único ponto: o diretório raiz /.

Diferente do Windows, o Linux não usa letras de unidade (C:, D:). Tudo — discos, dispositivos, configurações — está dentro da mesma árvore de diretórios.
DiretórioConteúdo
/Raiz do sistema — ponto de partida de toda a hierarquia
/homeDiretórios pessoais dos usuários (/home/usuario)
/binProgramas essenciais usados por todos os usuários
/sbinProgramas de administração do sistema (superusuário)
/etcArquivos de configuração do sistema
/tmpArquivos temporários (apagados ao reiniciar)
/usrProgramas e dados instalados pelo sistema
/varArquivos que mudam com frequência (logs, caches)
/devArquivos de dispositivos (discos, terminais)
/bootArquivos de inicialização do sistema
/libBibliotecas compartilhadas pelos programas
/mntPonto de montagem de dispositivos externos
/rootDiretório pessoal do superusuário (root)

O seu diretório pessoal é representado pelo símbolo ~. Ao abrir um terminal, você estará automaticamente em /home/seu_usuario.

bash
# Caminho absoluto: começa em /
/home/pedro/projetos/dados.csv

# Caminho relativo: parte do diretório atual
projetos/dados.csv   # equivalente, se você estiver em /home/pedro

# ~ é atalho para /home/seu_usuario
~/projetos/dados.csv  # equivalente

1.2 Comandos essenciais

O terminal recebe comandos no formato: comando [opções] [argumentos]. Opções começam com - (forma curta) ou -- (forma longa).

Navegação e inspeção

ComandoDescriçãoExemplo
pwdMostra o diretório atual (print working directory)pwd
lsLista arquivos do diretóriols -l  ·  ls -lh
cdNavega para o diretório indicadocd ~/projetos  ·  cd ..
whoMostra usuários logados na máquinawho
bash
pwd                   # /home/pedro
ls                    # lista arquivos simples
ls -l                 # lista detalhada (permissões, tamanho, data)
ls -lh                # como -l mas com tamanhos legíveis (KB, MB)
ls -la                # inclui arquivos ocultos (começam com .)
cd /home/pedro        # vai para esse diretório
cd ..                 # sobe um nível
cd ~                  # vai para o diretório pessoal
cd -                  # volta ao diretório anterior

Criação e manipulação de arquivos

ComandoDescriçãoExemplo
mkdirCria um diretóriomkdir dados  ·  mkdir -p a/b/c
touchCria arquivo vazio ou atualiza data de modificaçãotouch notas.txt
cpCopia arquivo(s)cp origem.txt destino.txt
mvMove ou renomeia arquivo(s)mv velho.txt novo.txt
rmRemove arquivo(s)rm arquivo.txt  ·  rm -r pasta/
manAbre o manual do comandoman ls
bash
mkdir projeto                    # cria o diretório 'projeto'
mkdir -p projeto/data/raw        # cria toda a hierarquia de uma vez
touch projeto/README.txt         # cria arquivo vazio

cp sequencias.fasta backup/      # copia para o diretório backup/
cp -r pasta_original/ copia/     # copia diretório recursivamente

mv resultado.csv resultados/     # move o arquivo
mv antigo.py novo.py             # renomeia o arquivo

rm temporario.txt                # remove (CUIDADO: sem lixeira!)
rm -r resultados_antigos/        # remove diretório recursivamente
rm -rf pasta/                    # força remoção sem confirmação (use com cuidado!)

man cp                           # abre o manual do comando cp (q para sair)

Leitura de arquivos

ComandoDescriçãoOpções úteis
catExibe todo o conteúdo do arquivo-n numera linhas
headExibe as primeiras 10 linhas-n 20 exibe 20 linhas
tailExibe as últimas 10 linhas-f acompanha em tempo real
lessExibe com rolagem (↑↓, q para sair)/termo busca no arquivo
wcConta linhas, palavras e bytes-l só linhas; -w só palavras
bash
cat sequencias.fasta             # exibe o arquivo inteiro
cat -n sequencias.fasta          # exibe com numeração de linhas

head sequencias.fasta            # primeiras 10 linhas
head -n 20 sequencias.fasta      # primeiras 20 linhas

tail sequencias.fasta            # últimas 10 linhas
tail -n 5 resultado.csv          # últimas 5 linhas
tail -f log.txt                  # acompanha arquivo crescente em tempo real

less arquivo_grande.txt          # navegue com ↑↓ PgUp PgDn; q para sair

wc sequencias.fasta              # linhas, palavras e bytes
wc -l sequencias.fasta           # apenas o número de linhas
wc -l *.fasta                    # conta linhas em todos os .fasta
Dica: Para inspecionar um arquivo desconhecido, comece com head para ver o formato, wc -l para saber o tamanho, e less para navegar pelo conteúdo.

1.3 Caracteres especiais

Certos caracteres têm significados especiais no shell. Conhecê-los é fundamental para construir comandos poderosos.

CaractereSignificadoExemplo
.Diretório atual./meu_script.sh
..Diretório pai (um nível acima)cd ..
~Diretório pessoal (/home/usuario)cd ~/projetos
*Curinga — representa qualquer sequência de caracteresls *.csv
?Curinga — representa exatamente um caracterels seq?.fasta
|Pipe — encadeia a saída de um comando na entrada do próximocat f.txt | grep "gene"
>Redireciona saída para arquivo (sobrescreve)ls > lista.txt
>>Redireciona saída para arquivo (acrescenta)echo "fim" >> log.txt
;Executa o próximo comando independentemente do resultadomkdir a; cd a
&Executa o comando em background, liberando o terminalprograma &
bash
# Curinga * lista todos os arquivos .fasta
ls *.fasta

# Curinga ? substitui exatamente um caractere
ls seq?.fasta       # seq1.fasta, seq2.fasta, mas NÃO seq10.fasta

# Redirect > cria (ou sobrescreve) arquivo com a saída
ls -l > inventario.txt

# Redirect >> acrescenta ao final do arquivo existente
date >> inventario.txt

# ; executa sequencialmente, independente de erros
mkdir resultados; cd resultados; touch README.txt

# & envia para background (programa continua rodando)
blast_longo &       # terminal fica livre para outros comandos

1.4 Editores de texto no terminal

Para editar arquivos sem interface gráfica — por exemplo, em servidores remotos via SSH — é essencial conhecer pelo menos um editor de texto no terminal.

EditorCaracterísticasQuando usar
nanoSimples, atalhos visíveis na telaIniciantes; edições rápidas
vimPoderoso, modos de edição (insert/normal/command)Uso avançado; muito presente em servidores
geditInterface gráfica, intuitivoDesktop com ambiente gráfico

nano — uso básico

bash
nano meu_script.sh   # abre (ou cria) o arquivo

# Dentro do nano:
# Ctrl+O  → salva o arquivo (Write Out)
# Ctrl+X  → sai do nano
# Ctrl+W  → busca no arquivo
# Ctrl+K  → recorta a linha inteira
# Ctrl+U  → cola

vim — sobrevivência básica

bash
vim arquivo.txt      # abre o arquivo

# O vim tem MODOS — ao abrir, você está no modo NORMAL
i          # entra no modo INSERT (pode digitar)
Esc        # volta ao modo NORMAL
:w         # salva
:q         # sai
:wq        # salva e sai
:q!        # sai SEM salvar (descarta alterações)

# No modo NORMAL:
/palavra   # busca "palavra" no arquivo (n = próxima ocorrência)
dd         # apaga a linha inteira
yy         # copia a linha
p          # cola
Dica: Se você se perder no vim e não conseguir sair, pressione Esc várias vezes e depois digite :q! para sair sem salvar.
