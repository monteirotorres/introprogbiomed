2.1

Pipes e redirecionamento

O poder da linha de comando vem da capacidade de encadear comandos simples usando pipes (|) e de redirecionar saídas para arquivos. Cada programa lê da entrada padrão (stdin) e escreve na saída padrão (stdout).

bash
# Pipe: saída de um comando vira entrada do próximo
cat sequencias.fasta | wc -l        # conta linhas do arquivo
ls -l | head -5                     # mostra só os 5 primeiros itens da lista

# Redirect > (sobrescreve) e >> (acrescenta)
ls *.fasta > lista_arquivos.txt     # salva lista de arquivos
echo "novo registro" >> log.txt     # acrescenta ao log

# Combinar: filtrar e salvar resultado
cat dados.csv | grep "Homo sapiens" > humanos.csv
Filosofia Unix: cada ferramenta faz uma coisa bem feita. A força vem da combinação — pequenos comandos encadeados constroem análises complexas sem escrever uma linha de código.
2.2

Busca e filtragem

grep — busca por padrões de texto

grep é uma das ferramentas mais usadas em bioinformática. Ele filtra linhas que contêm um padrão — literais ou expressões regulares.

bash
# Sintaxe básica
grep "padrão" arquivo.txt

# Buscar cabeçalhos em um FASTA (começam com >)
grep ">" sequencias.fasta

# -c conta o número de ocorrências
grep -c ">" sequencias.fasta        # número de sequências

# -i ignora maiúsculas/minúsculas
grep -i "BRCA" genes.txt

# -v inverte: mostra linhas que NÃO contêm o padrão
grep -v ">" sequencias.fasta        # apenas as sequências (sem cabeçalhos)

# -n mostra o número da linha
grep -n "error" log.txt

# Com pipe: filtrar CSV por coluna
cat expressao.csv | grep "cancer"

# Expressão regular: linhas que começam com um número
grep "^[0-9]" dados.txt

# Busca em múltiplos arquivos
grep "TP53" *.fasta

find — busca de arquivos no sistema

bash
# Buscar por nome
find . -name "*.fasta"             # todos os .fasta no diretório atual
find /home/pedro -name "dados*"    # arquivos que começam com "dados"

# Buscar por tipo
find . -type f -name "*.py"        # arquivos (-f) Python
find . -type d                     # apenas diretórios (-d)

# Buscar por tamanho
find . -size +10M                  # arquivos maiores que 10 MB

# Buscar e executar ação sobre cada resultado
find . -name "*.tmp" -delete       # apaga todos os .tmp encontrados

wc, sort e uniq — contar e ordenar

bash
wc -l arquivo.txt                  # conta linhas
wc -w arquivo.txt                  # conta palavras

sort nomes.txt                     # ordena alfabeticamente
sort -n numeros.txt                # ordena numericamente
sort -r arquivo.txt                # ordem inversa

# Contar valores únicos (uniq requer entrada ordenada)
cut -f2 tabela.tsv | sort | uniq           # valores únicos da coluna 2
cut -f2 tabela.tsv | sort | uniq -c        # + contagem de cada valor
cut -f2 tabela.tsv | sort | uniq -c | sort -rn  # ordena por frequência

cut e awk — manipulação de colunas

bash
# cut extrai colunas de arquivos delimitados
cut -d',' -f1,3 dados.csv          # colunas 1 e 3 de CSV
cut -d'	' -f2 tabela.tsv          # coluna 2 de TSV
cut -c1-10 sequencias.txt          # caracteres 1 a 10 de cada linha

# awk — processamento mais flexível
awk '{print $1, $3}' arquivo.txt           # imprime colunas 1 e 3
awk -F',' '{print $2}' dados.csv           # col 2 de CSV
awk '$3 > 100 {print}' tabela.txt          # filtra linhas onde col 3 > 100
awk 'NR > 1 {print}' dados.csv             # pula o cabeçalho (linha 1)

Processos e acesso remoto

Gerenciamento de processos

ComandoDescriçãoExemplo
topMonitor de processos em tempo realtop (q para sair)
htopVersão melhorada do top (interface interativa)htop
psLista processos em execuçãops aux
killEncerra um processo pelo seu IDkill -9 1234
jobsLista processos em backgroundjobs
bgRetoma processo pausado em backgroundbg %1
fgTraz processo de background para frentefg %1
bash
top                               # monitor ao vivo (q para sair)
ps aux                            # todos os processos do sistema
ps aux | grep python              # filtra processos Python

# Matar processo
kill 4321                         # sinal padrão (SIGTERM — gracioso)
kill -9 4321                      # força o encerramento imediato (SIGKILL)

# Background e foreground
programa_lento &                  # inicia em background
Ctrl+Z                            # pausa o programa atual
bg                                # retoma em background
fg                                # traz de volta para frente

SSH e SCP — acesso e cópia remota

bash
# Conectar a servidor remoto
ssh usuario@servidor.ufrj.br
ssh -XY usuario@192.168.1.10      # -XY habilita interface gráfica remota

# Copiar arquivos entre máquinas (scp)
scp arquivo.txt usuario@servidor:/home/usuario/      # local → remoto
scp usuario@servidor:/dados/resultado.csv ./         # remoto → local
scp -r pasta/ usuario@servidor:/destino/             # copia diretório inteiro

# Manter sessão ativa mesmo após desconexão (nohup)
nohup python3 analise.py &        # roda em background, sobrevive ao logout

Construindo pipelines biomédicos

Veja exemplos de pipelines reais que combinam os comandos aprendidos para resolver problemas comuns em bioinformática.

Pipeline 1 — Extrair IDs de um FASTA

bash
# Extrair todas as linhas de cabeçalho e salvar os IDs
grep ">" sequencias.fasta | cut -d' ' -f1 | tr -d '>' > ids.txt

# Quantas sequências tem o arquivo?
grep -c ">" sequencias.fasta

Pipeline 2 — Inspecionar e filtrar um CSV de expressão gênica

bash
# Ver cabeçalho
head -1 expressao.csv

# Contar amostras (linhas menos o cabeçalho)
tail -n +2 expressao.csv | wc -l

# Filtrar amostras de um tipo celular específico
grep "neuron" expressao.csv > neuronios.csv

# Top 10 genes mais citados em um arquivo de anotação
cut -d',' -f3 anotacao.csv | sort | uniq -c | sort -rn | head -10

Pipeline 3 — Processar múltiplos arquivos em lote

bash
# Contar sequências em cada FASTA de um diretório
for f in *.fasta; do
    echo "$f: $(grep -c '>' $f) sequências"
done

# Concatenar todos os FASTAs em um só arquivo
cat *.fasta > todas_as_sequencias.fasta
Exercício rápido: dado um arquivo genes.csv com colunas id, gene, organismo, expressao, escreva um pipeline que: (1) filtra apenas humanos, (2) ordena por expressão decrescente, (3) mostra os 5 mais expressos.
