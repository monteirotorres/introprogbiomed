3.1

Anatomia de um script Bash

NotebookBash

Um script Bash é um arquivo de texto com uma sequência de comandos. O shebang na primeira linha informa ao sistema qual interpretador usar.

bash
#!/bin/bash
# Isto é um comentário — linhas com # são ignoradas pelo shell

echo "Olá, mundo!"
echo "Hoje é: $(date)"

Para tornar o script executável e rodá-lo:

bash
chmod +x meu_script.sh    # dá permissão de execução
./meu_script.sh           # executa o script

# Alternativamente, sem precisar de chmod:
bash meu_script.sh

# Para depurar (mostra cada comando antes de executar):
bash -x meu_script.sh
Boas práticas: sempre inclua o shebang (#!/bin/bash), use nomes descritivos para variáveis, e adicione comentários para explicar o porquê, não o quê.
3.2

Variáveis e argumentos

Variáveis

bash
#!/bin/bash

# Atribuição (sem espaços ao redor do =)
ORGANISMO="Homo sapiens"
N_SEQUENCIAS=150
ARQUIVO="dados.fasta"

# Uso (sempre com $)
echo "Analisando: $ORGANISMO"
echo "Arquivo: $ARQUIVO"
echo "Total: $N_SEQUENCIAS sequências"

# Capturar saída de um comando em variável
DATA=$(date +%Y-%m-%d)
N_LINHAS=$(wc -l < $ARQUIVO)
echo "Data de hoje: $DATA"
echo "Linhas no arquivo: $N_LINHAS"

# Variáveis de ambiente comuns
echo $HOME       # diretório pessoal
echo $USER       # nome do usuário
echo $PATH       # caminhos de busca de programas

Argumentos posicionais

Scripts podem receber argumentos da linha de comando. Eles são acessados via $1, $2, etc.

bash
#!/bin/bash
# Uso: ./analisar.sh sequencias.fasta resultados/

ARQUIVO=$1       # primeiro argumento
SAIDA=$2         # segundo argumento

echo "Script: $0"       # nome do próprio script
echo "Arquivo: $1"      # primeiro argumento
echo "Saída: $2"        # segundo argumento
echo "Total de args: $#"  # número de argumentos
echo "Todos os args: $@"  # todos os argumentos

# Verificar se o argumento foi fornecido
if [ -z "$1" ]; then
    echo "Uso: $0  "
    exit 1
fi
Execução: ./analisar.sh sequencias.fasta resultados/

Estruturas de controle

Condicional if/elif/else

bash
#!/bin/bash
ARQUIVO=$1

# Verificar existência do arquivo
if [ -f "$ARQUIVO" ]; then
    echo "Arquivo encontrado: $ARQUIVO"
    N=$(grep -c ">" "$ARQUIVO")
    echo "Contém $N sequências"
elif [ -d "$ARQUIVO" ]; then
    echo "$ARQUIVO é um diretório, não um arquivo"
else
    echo "Erro: $ARQUIVO não encontrado"
    exit 1
fi

# Comparações numéricas
TAMANHO=$(wc -l < "$ARQUIVO")
if [ "$TAMANHO" -gt 1000 ]; then
    echo "Arquivo grande: $TAMANHO linhas"
elif [ "$TAMANHO" -gt 100 ]; then
    echo "Arquivo médio: $TAMANHO linhas"
else
    echo "Arquivo pequeno: $TAMANHO linhas"
fi

Operadores de teste comuns:

OperadorSignificado
-f arquivoExiste e é um arquivo regular
-d dirExiste e é um diretório
-z "$var"String vazia
-n "$var"String não vazia
$a -eq $bIgual (numérico)
$a -gt $bMaior que (numérico)
$a -lt $bMenor que (numérico)
"$a" == "$b"Igual (string)

Loop for

bash
#!/bin/bash

# Iterar sobre arquivos
for ARQUIVO in *.fasta; do
    N=$(grep -c ">" "$ARQUIVO")
    echo "$ARQUIVO: $N sequências"
done

# Iterar sobre uma lista
for ORGANISMO in "human" "mouse" "zebrafish"; do
    echo "Processando: $ORGANISMO"
    grep "$ORGANISMO" banco_dados.csv > "${ORGANISMO}_dados.csv"
done

# Iterar sobre uma sequência numérica
for i in {1..10}; do
    echo "Amostra $i"
done

# Iterar com seq (mais controle)
for i in $(seq 1 5 100); do   # 1, 6, 11, ..., 96
    echo $i
done

Loop while

bash
#!/bin/bash

# Processar arquivo linha a linha
while IFS= read -r linha; do
    echo "Processando: $linha"
done < lista_amostras.txt

# Contador com while
CONTADOR=0
while [ $CONTADOR -lt 5 ]; do
    echo "Iteração $CONTADOR"
    CONTADOR=$((CONTADOR + 1))
done
3.4

Funções

Funções encapsulam blocos de código reutilizáveis. Em Bash, elas são definidas antes de serem chamadas.

bash
#!/bin/bash

# Definição de função
contar_sequencias() {
    local arquivo=$1          # variável local à função
    local n=$(grep -c ">" "$arquivo")
    echo "$n"
}

verificar_arquivo() {
    local arquivo=$1
    if [ ! -f "$arquivo" ]; then
        echo "Erro: arquivo '$arquivo' não encontrado." >&2
        return 1              # código de saída de erro
    fi
    return 0
}

processar_fasta() {
    local arquivo=$1
    local saida=$2

    verificar_arquivo "$arquivo" || exit 1

    local n=$(contar_sequencias "$arquivo")
    echo "Arquivo: $arquivo | Sequências: $n"

    # Extrai IDs e salva
    grep ">" "$arquivo" | cut -d' ' -f1 | tr -d '>' > "$saida"
    echo "IDs salvos em: $saida"
}

# Chamada das funções
for f in *.fasta; do
    processar_fasta "$f" "${f%.fasta}_ids.txt"
done
Script completo de exemplo — relatório de FASTAs:
bash
#!/bin/bash
# relatorio_fasta.sh — gera relatório de arquivos FASTA em um diretório
# Uso: ./relatorio_fasta.sh 

DIR=${1:-.}    # usa argumento ou diretório atual como padrão
SAIDA="relatorio_$(date +%Y%m%d).txt"

echo "=== Relatório FASTA ===" > "$SAIDA"
echo "Diretório: $DIR" >> "$SAIDA"
echo "Data: $(date)" >> "$SAIDA"
echo "---" >> "$SAIDA"

TOTAL=0
for ARQUIVO in "$DIR"/*.fasta; do
    [ -f "$ARQUIVO" ] || continue           # pula se não houver .fasta
    N=$(grep -c ">" "$ARQUIVO")
    TOTAL=$((TOTAL + N))
    printf "%-40s %6d seqs
" "$(basename $ARQUIVO)" "$N" >> "$SAIDA"
done

echo "---" >> "$SAIDA"
echo "TOTAL: $TOTAL sequências" >> "$SAIDA"

echo "Relatório salvo em: $SAIDA"
cat "$SAIDA"
