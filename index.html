Introdução à Programação
para Pesquisa Biomédica

Aprenda Linux, shell scripting, Python e R aplicados à pesquisa biomédica. O curso combina fundamentos computacionais com análise de dados reais, culminando em um hackathon com datasets biomédicos públicos.

Sobre o curso

Este curso de 30 horas (10 aulas de 3h) é voltado para estudantes e pesquisadores da área biomédica sem experiência prévia em programação. Ao longo das seis primeiras aulas, você desenvolverá habilidades em Linux, automação com Bash, e análise de dados com Python e R ensinados em paralelo. As quatro últimas aulas são dedicadas a um hackathon com dados reais.

Pré-requisito: nenhum conhecimento prévio em programação é necessário. Ideal para quem tem um problema biológico e quer abordá-lo computacionalmente.

Hackathon (Aulas 7–10)

As últimas quatro aulas são dedicadas a um projeto em equipe com dados biomédicos reais. Cada equipe escolhe um desafio, constrói um pipeline completo e apresenta os resultados na aula final.

AulaAtividadeEntregável
7Kickoff — escolha do desafio, formação de equipes, exploração dos dadosREADME + estrutura no GitHub
8Desenvolvimento I — pipeline de pré-processamento e análise exploratóriaNotebook com EDA completa
9Desenvolvimento II — visualizações finais, interpretação e documentaçãoFiguras + seção de discussão
10Apresentação de trabalhos (10 min + 5 min perguntas por equipe)Repositório público no GitHub
Desafios sugeridos: análise de expressão diferencial (GEO/recount3), caracterização de variantes genômicas (ClinVar), análise de dados clínicos (TCGA/NHANES), ou anotação funcional de proteínas (UniProt + BLAST).
